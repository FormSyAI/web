# Tool marks

Claude, OpenAI (Codex), Cursor, TRAE and OpenCode marks are sourced from
`@lobehub/icons-static-svg` (https://github.com/lobehub/lobe-icons).
Git, Jira and Kubernetes marks are sourced from Simple Icons
(https://github.com/simple-icons/simple-icons).

Marks identify the named tools; ownership remains with their respective brands.
CI/CD and SGLang currently use generic Lucide workflow / CPU icons, not brand marks.
